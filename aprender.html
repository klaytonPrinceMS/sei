Sua jornada: do zero ao envio

Toque em cada passo para marcar como feito. Vale para Memorando, Ofício e a maioria dos processos.

0 de 8 concluídos

  1. Entre no SEI — use o link “SEI — Servidor” na página inicial. Confira a unidade no topo (troque com ALT+F11 se tiver mais de uma).
  2. Inicie o processo — menu Iniciar Processo → escolha o tipo (ex.: PA - Informações para Memorando/Ofício) → preencha especificação, interessados e nível de acesso.
  3. Inclua o documento — Incluir Documento → escolha Memorando, Ofício etc. → preencha o texto no editor.
  4. Anexe PDFs se preciso — Incluir Documento → Externo → tipo, data, formato PDF e nível de acesso, com arquivo legível.
  5. Assine — selecione o documento → Assinar → confira o cargo e a função → digite a senha do SEI.
  6. Confira o checklist — título claro, acesso correto, documentos assinados, destinatários (ver checklist abaixo).
  7. Envie — selecione o processo → Enviar Processo → escolha a unidade de destino → marque “manter processo aberto” só se ainda for trabalhar nele.
  8. Acompanhe — use Pesquisar, Acompanhamento Especial e Histórico para saber onde ele está.
💡 Memorando e Ofício geralmente usam o tipo PA - Informações. Confirme a tabela em Sistema → Tipos.
